The binary in this folder is a compiled version of the source code at https://github.com/Cubicake/Configurate
The fork adds commented yaml support from [Tim203](https://github.com/Tim203/Configurate) (the same as in Geyser's configurate),
plus some minor additions from myself, with updates from [SpongePowered](https://github.com/spongepowered/configurate) merged.

For now, I am directly committing the binary because I cannot be bothered to host it as a Maven artifact.

The current version is commit [`a999454`](https://github.com/Cubicake/Configurate/commit/a999454d4020c1437bc42527c657adcc0663d9e9) from https://github.com/Cubicake/Configurate
